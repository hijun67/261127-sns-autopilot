### 뉴스픽 — 핫기사 실제 파싱 + 파트너스 맞춤 RSS (`/api/sources/newspic`)
- `www.newspic.kr` → `m.newspic.kr` 순으로 받아 **서버 렌더 HTML에서 기사 목록을 파싱**한다. 실측: 2026-11-28 09:36 KST 기준 `https://m.newspic.kr/` **HTTP 200**, 기사 8건(제목·`/view.html?nid=…` 링크·`images-cdn.newspic.kr` 썸네일·언론사/날짜 요약) 파싱 성공. CSR 차단이 아니라서 폴백 없이 동작한다.
- 사용자가 설정에 넣은 **뉴스픽 파트너스 맞춤 RSS**도 파싱(`<item>`/Atom `<entry>`, CDATA·엔티티·`media:content`·`enclosure`). RSS가 RSS/Atom XML이 아니거나 항목이 없으면 이유를 `rssError`로 돌려준다.
- **SSRF 방지**: 서버가 대신 호출하는 URL은 `http(s)://*.newspic.kr`만 허용. 그 밖의 주소는 400 안내.
- `articles` = 핫기사 먼저 + 내 RSS, 같은 링크는 1회.

### 뉴스픽 파트너스 전용 포맷 — 본문 / 연결 댓글 분리
- **본문**: 후킹 **2~3줄**, 링크 없음(테스트로 `http` 부재 확인). X·Threads·Facebook 문구도 본문만 쓴다.
- **연결 댓글**: `제휴 링크 + 댓글 유도`. 대가성 문구가 켜져 있으면 댓글 끝에 붙는다.
- 결과 패널·SNS 탭에 **본문 복사 / 연결 댓글 복사** 버튼 분리. AI 프롬프트에 `partner.body`·`partner.comment` 스키마를 넣고, AI가 본문에 링크를 넣으면 제거 후 3줄로 자른다.
- 큐 항목에 `partnerBody`·`comment`를 함께 저장하고 **댓글 복사** 버튼을 추가.

### 브랜드커넥트 · 토스 쉐어링크 — 제휴 URL 풀 + 토스 설정
- 설정의 **제휴 URL 풀**(상품명·URL·종류)에 여러 개 등록/삭제. 소스 종류별로 거르고, 없으면 `기타` → 전체 순 폴백.
- 스튜디오 **🎲 랜덤 뽑기** → 상품명·링크 자동 입력.

## 4. 남은 점·알릴 점
- **쿠팡 실 상품 조회는 이번에 실키로 검증하지 못했다.** 키가 없어서 400 안내와 HMAC 서명 규격(테스트로 node crypto 결과와 일치 확인)까지만 검증했다. 사용자가 쿠팡파트너스 Access/Secret Key를 넣으면 바로 동작하며, 401이 나면 키 오류 메시지가 뜬다.
- 쿠팡 구 카테고리 경로(`v1` 없는 경로)는 넣지 않았다. 404가 나면 v1 경로 문제일 수 있어 그때 폴백을 추가하면 된다.
- 뉴스픽 파트너스 **실제 맞춤 RSS 주소는 아직 등록되지 않았다.** 핫기사 경로는 실측 동작하고, RSS는 `*.newspic.kr` 주소만 받는다(보안).
- 브랜드커넥트는 공식 오픈 API가 없어 URL 풀 방식으로, 토스는 IP 등록 제약 때문에 키 입력칸 + URL 풀을 함께 두었다.
- 토스트가 3개까지만 쌓이도록 바꿨다(기존에는 복사 버튼을 가렸다).
