## 2. 확인된 결함 (심각도 순)

### A. [높음] 카드뉴스 Canvas 배경이 불투명하지 않아 PNG가 반투명 → 게시하면 글자가 안 보임
- 증상: 내려받은 `cardnews-01.png`(1080×1080)의 **픽셀 98%가 alpha 250 미만**(최소 alpha 31~46). 흰 배경으로 합성하면(=인스타그램·스레드가 JPEG로 변환할 때의 모습) 흰 제목이 연한 베이지 위에 깔려 판독 불가.
- 원인: `public/js/cardnews.js` `drawSlide()`가 `clearRect` 후 **불투명 베이스 채우기 없이** 그라디언트만 채우는데, 그라디언트 마지막 stop이 `hexToRgba(accent, 0.12)`(라이트)/`0.18`(다크)라서 알파가 남음. CSS `.card-canvas{background:#0b1020}`이 비쳐 페이지 미리보기와 파일이 서로 다르게 보임.
- 부수 증상: **라이트 모드에서 카드뉴스 미리보기가 갈색**으로 보이고 본문 대비가 낮음(다크 네이비 배경이 비침).
- 증빙: `evidence/dark-card-png-flattened-on-white.png`(흰 배경 합성), `evidence/light-mode-card-canvas-preview.png`(라이트 미리보기), `downloads/all-00-cardnews-01.png`.

### B. [높음] JSON 불러오기 후 새로고침하면 복원한 큐가 사라짐
- 재현: 오늘 스케줄 채우기(4건) → JSON 내보내기 → 큐 비우기 → JSON 불러오기(4건 표시) → **새로고침 → 0건**.
- 원인: `app.js` `#importFile` 핸들러가 `state = result.state` 후 `persist()`를 호출하지 않음 → localStorage에는 비운 상태가 남음. 이후 다른 조작(주기 변경 등)을 한 번 하면 그때 저장되어 유지됨.
- 증빙: `report_extra.json` → `import_persistence` (memory 4 / localStorage 0 / reload 0), `import_persistence_after_other_action` (reload 4).

### C. [중간] '수익 목표 믹스' 막대가 어느 테마에서도 채워지지 않음
- `.mix-fill`이 `span`(display:inline)이라 `width:30%;height:100%`가 적용되지 않아 실제 크기 0×0. 숫자(%)만 보이고 막대는 빈 트랙.
- 증빙: `evidence/mix-bars-dark.png`, `evidence/mix-bars-light.png`.

### D. [중간] '오늘 스케줄 채우기'가 이미 지난 시각 슬롯도 오늘 날짜로 큐에 넣음
- 16:40에 12회 채우기 → 07·09·11·13·15시(오늘) + 01·03·05시(오늘)까지 **12건 중 8건이 과거 시각**. 24회 → 24건 중 17건(00~16시)이 과거.
- 12회 타임테이블의 01·03·05시는 자정을 넘긴 다음 날 시간인데 오늘로 배정됨.

### E. [중간] 대시보드 '오늘 예약' KPI가 큐가 비어도 주기 숫자를 표시
- 큐 0건인데 `오늘 예약 4`, `슬롯 4개 대기`로 표시(`todays.length || freq`). 실제 예약은 0건.

### F. [중간] 모바일 생성 결과 '블로그' 탭 목차가 두 칸으로 갈라져 겹쳐 읽힘
- `.mini-list li{display:flex}` 때문에 `<strong>`(소제목)과 본문 텍스트가 각각 flex 아이템이 되어 390px에서 "· 연말정산 … 무엇 — 기준일과 적용 범위 / 예외 / 부터 볼까 …… 조건 확인"처럼 어긋나 보임.

### G. [낮음] 캔버스 줄바꿈이 글자 단위
- "순/서", "배송·구성 / 차이", "그르는 기 / 준을"처럼 어절 중간에서 끊김(어절 단위 줄바꿈 필요).

### H. [낮음] 긴 이름이 ellipsis로 잘려 의미가 사라짐 (1440에서도)
- 소스 버튼: "뉴스픽 파트너스 · 조회수 · 트래픽 · 목…", "네이버 브랜드커넥…", "내 사이트 · 목표 변…" — '목표 변경 권장' 안내가 잘려 보이지 않음.
- 목표 카드: "네이버 홈판 · 애…", "숏폼 조회수 · 리/워드", "브랜드 협찬 · 원…".

### I. [낮음] 큐 목록이 최신 시각이 위(내림차순)
- 22:00 → 18:00 → 13:00 → 09:00 순. 하루 흐름을 위에서 아래로 읽기 어려움.

### J. [낮음] 큐 항목 개별 삭제 불가
- 항목별 동작은 승인·발행·복사·건너뛰기·보기뿐. 잘못 만든 1건을 지우려면 '큐 비우기'로 전체를 비워야 함.

### K. [낮음] 멀티 채널 패키지 → '큐에 등록'이 9개를 같은 시각에 몰아넣음
- 예: 08:00 슬롯에 9개 채널 9건 동시 등록. 하루 채우기의 채널 순환 배분과 일관되지 않음.

### L. [낮음] 토스트가 연속 동작에서 최대 9개까지 쌓여 화면 우측을 가림
- (클릭은 통과 — `pointer-events:none`)

### M. [낮음] 기타
- '브랜드 표기' 기본값이 `한일 님` → 카드뉴스 하단에 개인 이름이 브랜드로 박힘. 비우고 저장해도 `한일 님`으로 복원.
- 목표 비중 슬라이더: 45%로 올려도 저장 시 합계 100 정규화로 36%로 표시(값이 되돌아간 것처럼 보임, 최대 60%).
- 키워드 비우고 생성 시 기본 주제가 어색함: "자체 생성 주제", "연말 홈템 가격 비교 **비교** 테스트 결과"(단어 중복).
- 라이트 모드 작은 라벨 대비 소폭 미달: `.tag` 4.05, `.eyebrow` 3.74 (본문은 4.5 이상).
- 모바일 하단 네비에 '수익 목표' 없음(대시보드 '조정 →'로만 접근).
- 카드뉴스는 제휴 소스+대가성 ON일 때 8장, 그 외 7장(최대 8장 사양).

## 3. 정상 확인 내역

- 로드: HTTP 200, 콘솔/페이지 에러 0(자체 점검용 `/api/generate` 400 응답 2건 제외), 실패 요청 0, 404/500 0, 보안 헤더(X-CTO·XFO·Referrer-Policy·Permissions-Policy) 정상.
- 가로 넘침: 데스크톱·모바일 전 뷰(대시보드/스튜디오/카드뉴스/큐-24회/채널/목표), 다크·라이트 모두 0.
- `/api/generate`: GET 200(providers 3종) / 키 없음 400 / 미지원 제공자 400 / 잘못된 키 502 / 깨진 본문 400.
- 소스 7종 전환 시 입력 라벨(상품명·브랜드 / 키워드·주제 / 페이지 주제)·힌트·'목표 변경 권장' 표시 변화 정상.
- 목표 9종: 전환 시 제목·훅·태그 변화 정상(예: 판매수수료 "사기 전에 꼭 비교해야 하는 한 가지", 애드센스 "계산·비교, 직접 해보면 답이 보입니다", 뉴스픽 "핵심만 남기면 이렇게 됩니다").
- 대가성 토글 ON/OFF: 카드 8↔7장, 블로그 HTML·캡션 문구 삽입/제거, 결과 패널 안내 표시/숨김.
- 4탭: 쇼츠(3초 훅+6씬+캡션), 카드뉴스 8장, 블로그(본문 722자·HTML 1,268자), SNS(X 5트윗 39~129자, Threads 160자, Facebook).
- 복사: HTML 복사 내용이 상태 HTML과 완전 일치, 텍스트/스레드/전체 복사 정상, 토스트 표시.
- 카드뉴스: 1080×1080 캔버스 8개, 장별 PNG·전체 PNG 8건 다운로드(1.88~1.94MB, 유효한 PNG) — 단 알파 결함(A).
- 주기 1/2/4/6/12/24회 시각 안내 문자열 명세와 완전 일치.
- 하루 채우기 4건(09·13·18·22시, Instagram/Threads/Facebook/X 순환), 승인→발행(되돌리기 없음), 건너뛰기→되돌리기, 복사, 보기(해당 콘텐츠로 스튜디오 이동) 정상. 자동 모드 → API 채널 자동 승인. 중복 채우기 방지 안내 정상.
- 큐 필터(전체/대기/승인/발행/건너뛰기), '대기 모두 승인' 정상. 설정 JSON 내보내기·설정 초기화(확인창) 정상.
- 채널 9개 연결 토글·핸들 저장·새로고침 유지, 네이버/티스토리 'API 종료 · 원클릭 복사' 배지 정상.
- 생성 결과 새로고침 유지(lastGenerated) 정상. 테마 전환 시 레이아웃 붕괴·넘침 없음(본문 대비 4.5 이상).
- 모바일: 하단 네비 5개·사이드바 숨김·본문 하단 여백 92px, 카드뉴스 1열(328px), 큐 행 328×137·버튼 35px, 설정 모달 352×743(뷰포트 내·가로 넘침 없음), 라이트 모드 정상.
